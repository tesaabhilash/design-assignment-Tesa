FIFO Use Case

About:
This project demonstrates a FIFO-based data processing system in Verilog. Serial input data is received by the front-end module (`face_mod`), converted into 8-bit parallel data using a Serial-In Parallel-Out (SIPO) register, stored in a FIFO buffer, and then processed by an FSM-based output module (`mod_out`).

The waveform shows serial data being converted into bytes, written into the FIFO buffer, read from the FIFO, and processed by the output module. The FIFO serves as temporary storage between data acquisition and processing stages.

Notes:
The design consists of multiple modules working together. The `face_mod` receives serial input data, the `sipo8` module converts the serial stream into 8-bit words, the FIFO buffers the generated bytes, and the FSM-based `mod_out` processes the buffered data. The complete system was verified using a dedicated testbench, demonstrating successful data transfer through each stage of the design.

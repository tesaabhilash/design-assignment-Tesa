## FIFO Transaction Class

About:
This project defines a SystemVerilog transaction class for the FIFO design. The class encapsulates randomized input signals and output signals along with a constraint and display function for verification purposes.

Files:
*[design file](design/top.v)
* [Transaction Class](transaction_class)

Notes:
The transaction class was written as a building block for class-based verification of the FIFO design, following standard SystemVerilog OOP conventions.
